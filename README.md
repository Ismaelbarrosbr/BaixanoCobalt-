# BaixanoCobalt

Comando para o Claude Code: `/baixar-cobalt-video <link> [estilo]`

Baixa um vídeo pelo [cobalt.tools](https://cobalt.tools) (ou yt-dlp como alternativa), traz o arquivo para o chat e edita no estilo pedido.

Créditos ao projeto cobalt, gratuito e de código aberto. Apoie: https://cobalt.tools/donate

O comando fica em `.claude/skills/baixar-cobalt-video/SKILL.md`. Sessões do Claude Code que usam este repositório (inclusive na nuvem) já reconhecem o comando.
